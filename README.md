# Creación de un repositorio Git desde Visual Studio Code

Este proyecto consiste en crear y trabajar con un repositorio Git desde el entorno de trabajo de Visual Studio Code.

## Finalidad

Su objetivo es poner en práctica los contenidos aprendidos en el módulo **«Fundamentos de Git y GitHub»**, trabajando con un repositorio y sus archivos desde Visual Studio Code.

## Contenido del repositorio

El repositorio incluye varios archivos de texto utilizados durante la práctica:

- `mensaje.txt`
- `mensaje2.txt`
- `repo3-rocio/mensaje3`
